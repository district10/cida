# 快速问答

2026-10-04 加入（本仓库 fork 的功能）。辞达原本的翻译/润色一个不动，另加一条「弹窗里问一句、接着追问」的路，
答完一轮就把这一轮的问答记进笔记（`spec/notes.md` §六）。与 `spec/panel.md` 同一套界面约定（浮窗、不抢焦点、纸与墨），
状态见 [`boards/chat.html`](../boards/chat.html)。

为什么：日常想问一句「这个命令是什么意思」「这段话怎么改」时，不值得切到另一个 AI 应用再切回来；
辞达已经住在菜单栏、已经配好了模型，弹一个窗就能问，答案还顺手留在自己的收件箱里。
它不是对话历史：**重新打开就是新对话**（§五），留不住的只有这一次的上下文，留下的都在笔记文件里。

## 一、入口与窗口

- 默认组合 ⌥C（`chat-shortcut`／设置里的「快速问答」可改，也可不设置）；菜单栏「快速问答」是同一入口，跟随组合显示按键。
- 窗口是辞达的浮窗（与面板同一套：无边框、圆角、`panel-edge` 描边、`panel-shadow` 投影、
  `nonactivatingPanel`，不激活辞达、不夺前台应用的焦点），宽度 640（`chat-width`）。
- 高度 = min(560 (`chat-max-height`), 屏幕可见高度 × 0.6 (`chat-max-ratio`))，顶边与面板同一条
  （`panel-top-ratio`，`CidaDesign.Panel.topEdge`），水平居中于鼠标所在的那块屏幕。高度不随内容变化：问答区在里面滚动。
- 与面板同时只留一个：⌥C 开窗时收起翻译面板，⌥A/⌥S 开面板时收起问答窗（两者都在屏幕顶部居中，叠在一起没有意义）。
- **不因失焦而关闭**：点到别的应用，窗口留在原处（对话要能一边看一边用别的应用）；Esc、⌥C 或菜单栏再次点击才收起。
- 收起不取消正在生成的回答：那次回答照常跑完、照常记进笔记（§四）；窗口里那一段下次打开就没了（§五）。
- **带入选区**（2026-10-04 加）：按 ⌥C 时前台应用里正好选中了文字，就把这段文字**引用进输入栏**（§二），
  引用在窗口出现时就位，光标停在引用块下面那一行空行上，接着打一句想问的即可。
  读数与 ⌥A/⌥N 同一条路径（辅助功能优先，读不到时让前台应用复制一次再放回剪贴板），所以也读密码框以外的普通选区。
  没有选中文字、或没有辅助功能权限时，窗口照常打开、输入栏空着：**这里不申请权限、不弹任何提示**——
  问答本身不需要选区，为了一句引用去要权限不值得。
  菜单栏「快速问答」是同一扇窗，但不读选区（菜单栏是辞达自己的，没有"用户选中了什么"这回事，与「显示辞达」一致）。

## 二、窗口里有什么

自上而下三块：

- **问答区**：本次对话的全部轮次，在里面滚动；提问后自动滚到底部，流式回答期间也一直贴着底部。
  一轮 = 两段相邻的纸：
  - 提问：`surface` 白底，界面字体（Inter 16 / 26pt 中文回退苹方）`text-primary`，与面板原文栏同一排版。
  - 回答：`surface-paper` 纸底，结果字体（衬线，中文 Noto Serif SC 17 / 31pt、西文 Source Serif 4 17.5 / 29pt）`text-ink`，
    与面板结果栏同一排版；流式期间行尾是那枚呼吸的 accent 光标（`spec/streaming-motion.md` 同一套）。
    面板的结果栏按增量只排版新增的一段，这里的纸是整段重排，所以流式文本**最多每 33ms 交给界面一次**（每次仍是完整的一段）：长回答也不会每个分片都重排一遍。
  - 两段之间与轮次之间是 1px `border` 细线；回答的左右内缩与提问相同（`space-window-x`）。
- **输入栏**（窗口最下，永远在）：一条 `border` 细线之上，与面板原文栏同一个编辑器
  （`ComposerTextEditor`，Inter 16 / 26pt、无拼写检查、粘贴大文档同样处理），占位「问一句，回车发送…」；
  输入多行时长高，最多 `chat-input-max-height`（160pt）之后内部滚动。
  - ⏎ 发送；⇧⏎ / ⌥⏎ 换行；输入法组字时 ⏎ 先交给输入法（与面板一致）。
  - 右侧一个动作胶囊，与面板控制栏同一个样式：有字且没在生成时是「发送 ⏎」；正在生成时是「停止 ⌘.」；空输入时不显示。
  - **引用块**：带入选区时（§一）输入栏里就是一段普通文字，每行前面是 `> `（空行只写一个 `>`，Markdown 的写法），
    块下面空一行；光标停在那一行。它和手打的字没有任何区别：可以改、可以删、可以整段重写，发送时原样进这一轮的问题（§四 的笔记里也是它）。
- **空对话**：问答区什么都不画（不做欢迎语、不做示例问题）；窗口看起来就是一个只有输入栏的空窗。

## 三、一轮问答

- 发送：把这一轮的问题追加进对话，向配置的模型服务发一次请求（`spec/configuration.md` 同一份配置：端点、模型、Key、格式），
  回答流式落进这一轮的纸面。同一时刻只有一次请求；上一次还在生成时「发送」不可用（要先停止）。
- 请求的形状是**多轮对话**而不是单段文字：system 是设置里的系统提示词（`chat-prompt`，留空用默认，§六），
  之后按顺序是本次对话的全部 user / assistant 消息（`chat-completions` 放进 `messages`、`responses` 放进 `input`、
  `anthropic-messages` 放进 `messages`），模型因此能接着上一轮说。
- 系统提示词不套翻译/改进那层「Application contract」（那是给文字转换任务用的）；它就是模型的身份与要求，原样写进请求。
- ⏎ 在问答区已经生成完时用新问题再发一轮，上一轮的问答留在窗口里，模型也看得到。
- 停止（⌘.）：当前回答停下，「已停止」这一轮不进笔记（§四）；输入栏里已经打好的字不受影响。
- 失败：这一轮的纸面上写原因（`请求失败：<原因>`，与面板同一套错误文案），可以再发一次；失败的一轮不进笔记。
- 模型没配置：不发请求，窗口里提示先配置（问答区写一行「还没有配置模型服务 · ⌘, 打开设置」）。

## 四、记进笔记

- 每次回答**完成**（`completed`）后追一行进笔记文件（`spec/notes.md` §二 的同一份文件、同一条去重）：
  - `source` 为 `"chat"`；
  - `text` 是**到这一轮为止的全部问答**，合在一起的一段文本（§五 的增量合入）：
    第 1 轮是 Q1A1，追问一次就是 Q1A1Q2A2，直到对话结束；
  - `note` 为 `null`（这条记录本身就是一整段对话，没有「原文/结果」两侧可分）；
  - `app` 是唤起窗口时所在的应用（与面板的 ⌘S 同一规则：辞达自己在前台时记 `null`）；
  - `ts` 是回答完成的时刻。
- 一轮一行，各写各的：同一段对话第 2 轮的行包含第 1 轮的内容，不去改写上一行（只追加、不重写，`spec/notes.md` §二）。
  于是 `jq -r 'select(.source == "chat") | .text' ~/.cida/items.jsonl` 里最后一行就是这场对话的全貌。
- 行与行之间的分隔与「问」「答」标签，就是窗口里那两段纸的文本投影：

  ```
  问：这个命令里的 -p 是什么意思？

  答：-p 是 --parents 的缩写，……

  问：那 -m 呢？

  答：-m 是 --message……
  ```

- 静默：没有人为这一条按过键，成功不弹提示胶囊；写失败时胶囊照旧说「存入失败：…」，日志记 `note-saved-chat`／`note-chat-failed`。
- 被停止、失败的轮次不记；整段对话超过 10 万字符（`NoteStore.maximumResultCharacters`）时这一轮不记，日志记 `note-chat-too-long`。

## 五、重开就是新对话

- 每次打开窗口（⌥C、菜单栏、诊断）都是**新对话**：上一个对话的轮次、输入栏里的草稿、失败与停止的状态全部丢掉；
  正在生成的那次请求随之取消（那次回答不再记进笔记）。
- 因此窗口收起再打开＝清空重置；收起本身不动正在生成的请求，也不动已经写下的笔记。
- 辞达不做对话历史、不读回笔记文件；要回看就在笔记文件里看（§四）。

## 六、设置与命令行

- 设置 → 快捷键 → 快捷键组新增一行「快速问答 · 弹窗里问一句，答案记进笔记」，与其它五个一样可录制、可清空、不能重复。
- 设置 → 动作 → 「问答」组：一行「系统提示词 · 快速问答里模型的身份」，一个铺满控件列的输入框，
  写的就是默认值本身（字段里直接显示），超过一列宽时按框宽裁掉、横向滚动看全；清空后失焦恢复默认。
  长提示词用命令行写、读（§七）。
- 默认系统提示词（`CidaSettings.defaultChatPrompt`）：

  > You are a helpful assistant. Answer the user's question directly and concisely. Reply in the language the user writes in.

- 命令行新增两个字段：

  ```sh
  cida config set chat-shortcut=control+option+c   # none 表示不设置
  cida config set chat-prompt --file prompt.txt    # 长提示词用 --file 或 --stdin
  cida config unset chat-prompt                    # 回到默认
  ```

## 七、不变的东西

- 翻译、改进、截图翻译、原处翻译、整窗翻译与它们的快捷键、提示词、模型配置全部照旧；问答不占用它们任何一处逻辑，
  只是同一个模型服务上的另一次请求。
- 不新增权限：读写文字都在辞达自己的窗口里，不需要辅助功能；带入选区（§一）用的是已有的辅助功能权限，
  没有它窗口照常打开、只是没有引用。
- 不记历史、不建索引、不做多会话管理：窗口是一次性的，留下来的只有笔记文件里那几行。
